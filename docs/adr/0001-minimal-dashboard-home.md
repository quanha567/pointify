# Minimal Dashboard-First Home Page

## Context
Pointify is built for agile teams needing immediate, frictionless estimation meetings. Traditional marketing-heavy landing pages introduce unnecessary scrolling and clicks before reaching the action.

## Decision
We chose a minimal app-first dashboard layout for the root page (`/`) instead of a marketing landing page. The home page features split action cards for Instant Room Creation (via a structured modal with preset Decks and initial roles) and Direct Room Joining (via room code input), alongside local recent rooms history without mandatory authentication.
