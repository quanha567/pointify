# Pointify Web

Frontend application for Pointify built with **Vite+**, **TypeScript**, and **Bun**.

## Tech Stack

- **Toolchain**: [Vite+](https://viteplus.dev/) (powered by Vite, Rolldown, tsdown, Oxlint, Oxfmt)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Package Manager**: [Bun](https://bun.sh/)

## Getting Started

### Installation

```bash
bun install
```

### Development & Build

```bash
# Start development server
bun run dev

# Type check
bun run typecheck

# Check formatting, linting & types
bun run check
bun run check:fix

# Format code
bun run format

# Production build
bun run build

# Preview build locally
bun run preview
```
